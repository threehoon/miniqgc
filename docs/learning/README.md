# Learning system — MiniGCS × QGC

在 **实现 Mini** 的同时 **对照 QGC** 学习。实现进度看 `docs/project/`；这里管「学到了什么」。

## 四步（每个竖切固定）

```text
① 业务导读 → ② 场景与边界 → ③ Mini 实现 → ④ 对照 QGC 笔记
```

禁止只写代码不写对照（除非 PROGRESS 里注明跳过原因）。

## 文件

| 文件 | 作用 |
|------|------|
| [PLAN.md](PLAN.md) | 学习/实现对照总计划 |
| [PROGRESS.md](PROGRESS.md) | 学习进度（对照理解程度） |
| [notes/](notes/) | 分里程碑笔记 |
